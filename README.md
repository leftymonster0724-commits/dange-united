# ⚽ Dange United O-40 公式ホームページ

社会人サッカーチーム「Dange United O-40」の公式ウェブサイトです。
40歳以上（35歳以上も参加可）を対象としたチームの公式情報発信・メンバー募集・スポンサーPRを目的としています。

---

## 🎯 サイト目的

- **新規メンバー募集** - 入会体験・募集要項の周知
- **試合結果の発信** - リーグ戦・大会の結果・日程の発信
- **活動紹介** - チームの特徴・選手・スタッフの紹介
- **スポンサー向けPR** - 協賛プランの提案・現スポンサーの掲載

---

## 🗂️ 完成ページ一覧

| ファイル | ページ名 | 主な内容 |
|---|---|---|
| `index.html` | トップページ | ヒーロービジュアル、最新試合結果、特徴紹介、ギャラリー、最新ニュース、メンバー募集CTA、スポンサーバナー |
| `about.html` | チーム紹介 | チームの歴史・理念・活動内容・基本情報 |
| `players.html` | 選手・スタッフ紹介 | コーチングスタッフ、登録選手一覧（ポジション別） |
| `schedule.html` | 試合日程・結果 | タブ切り替え式シーズン別スコア一覧、次の試合案内 |
| `news.html` | ニュース | カテゴリフィルター付きニュース一覧 |
| `recruit.html` | メンバー募集 | 募集要項・入会の流れ・FAQ・体験申し込みCTA |
| `sponsor.html` | スポンサー | スポンサープラン（Gold/Silver/Bronze）・現スポンサー掲載 |
| `contact.html` | お問い合わせ | 種別選択付きお問い合わせフォーム・直接連絡先 |

## 🔧 今後の対応推奨事項

1. **チーム情報の更新**
   - 実際のチーム名・代表者名・連絡先メールアドレス (`info@dange-united.jp`) を実際のものに変更
   - 練習場所の正確な名称・住所を更新
   - 選手・スタッフ情報を実際のデータに差し替え

2. **画像の差し替え**
   - `images/` フォルダの写真を実際のチーム写真に差し替えると一層リアルになります

3. **SNSリンクの設定**
   - フッター・コンタクトページの SNS リンク (`href="#"`) を実際のアカウントURLに変更

4. **お問い合わせフォームのバックエンド連携**
   - 現在は擬似送信（デモ表示）です。実際にメールを送受信するには FormSubmit や EmailJS 等の外部サービスとの連携を推奨

5. **Google Mapsの埋め込み**
   - 練習場所のマップ埋め込みを追加すると利便性が向上します

6. **試合結果・ニュースの定期更新**
   - 試合のたびに `schedule.html` と `news.html` を更新してください
